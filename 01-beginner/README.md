# Tier 1 — Beginner

Goal: get a working ROS2 development environment and understand the core
building blocks every ROS2 system is made of, ending with your first robot
moving around inside a physics simulator.

Nothing here assumes prior robotics knowledge. It does assume you're
comfortable writing and running Python and/or C++ code from a terminal.

## Chapters

1. [Dev environment](01-dev-environment/OVERVIEW.md) — installing ROS2,
   setting up a workspace, verifying the install.
2. [ROS2 core concepts](02-ros2-core-concepts/OVERVIEW.md) — nodes,
   topics, publish/subscribe.
3. [Services & Actions](03-services-and-actions/OVERVIEW.md) —
   request/response and long-running goal patterns.
4. [Parameters & Launch files](04-parameters-and-launch/OVERVIEW.md) —
   configuring nodes at runtime, starting multiple nodes together.
5. [Robot description (URDF/Xacro)](05-urdf-xacro/OVERVIEW.md) —
   describing a robot's physical structure.
6. [Debugging & visualization tools](06-debugging-and-visualization/OVERVIEW.md)
   — RViz2, rqt, and ros2 bag.
7. [Gazebo basics](07-gazebo-basics/OVERVIEW.md) — your first robot
   simulation, driving a robot around.

Start with Chapter 1 — it installs everything the rest of the tier needs.
